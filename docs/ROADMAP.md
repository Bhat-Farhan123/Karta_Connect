# Karta Connect Roadmap

This roadmap records planned work. Items listed here should not be treated as implemented unless verified in the application.

## Platform Improvements

- Complete end-to-end verification of all role portals.
- Verify persistent job and application workflows.
- Complete messaging authorization and message-request workflows.
- Verify scholar resume visibility and secure file access.
- Verify invitation email delivery and account activation.
- Recover and maintain the authoritative Supabase SQL migration history.
- Add automated tests for critical workflows.
- Improve frontend bundle splitting and loading performance.

## Skill Assessments

Planned capability:

- Admins or authorized organizations can create assessments.
- Scholars can take assigned assessments.
- Results can be made available in appropriate scholar profiles and application workflows.

This feature is planned and is not confirmed as implemented.

## Alumni Network

Planned capability:

- Connect alumni and current scholars.
- Support professional networking and mentorship.
- Provide relevant alumni discovery and profile information.

Some alumni-facing interface elements exist, but the complete networking workflow is not confirmed as implemented.

## Future Infrastructure

- Review storage retention and deletion requirements.
- Evaluate future Azure integration if required.
- Consider a mobile application after the web platform workflows are stable.

## Roadmap Status

Prioritize security, database consistency, and completion of existing workflows before introducing additional major features.
