# Karta Connect Frontend

React + Vite frontend. See the root README and docs/ARCHITECTURE.md for project architecture.

## Setup

1. Run npm install in this directory.
2. Create .env.local using .env.example.
3. Set VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY.
4. Run npm run dev.

## Build

Run npm run build.
